This blog is built with [Hugo](https://gohugo.io/), a static site generator that turns content files and templates into a site of plain HTML, CSS, and other assets.

Posts live in Markdown files under `content/posts/`. Each one begins with front matter for its title, date, tags, and publication status. The Paper theme supplies the layouts that turn those files into pages.

To preview the site locally, run `hugo server` from the directory containing `hugo.toml`. Hugo watches the content files and refreshes the preview when they change.

The nice part is that writing remains simple: add a Markdown file, give it a title, and focus on the idea you want to share.
